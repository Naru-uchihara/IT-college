## 1. 概要

### 1.1 目的
売上・案件・人事の情報を一つのWebアプリで管理する。今は散らばっている情報を集めて、次のことを実現する。

- 売上の推移や目標の達成状況をすぐ把握できる
- 案件の担当者・納期・進捗を全社員が同じ情報で確認できる
- 社員情報・給料・参加案件をまとめて管理できる

### 1.2 対象範囲
| 対象 | 内容 |
| --- | --- |
| 売上管理 | ダッシュボード、年月ごとの売上詳細表 |
| 案件管理 | 案件一覧表、案件詳細ポップアップ |
| 人事管理 | 社員の個人情報、給料、参加している案件 |
| 共通 | サイドバーによる画面遷移、ログイン、CSV/Excel取り込み |

### 1.3 利用者
- 全社員(全員同じ権限。すべての画面を閲覧・登録・編集・削除できる)

## 3. 画面構成

### 3.1 全体レイアウト
- 画面の左側に**サイドバー**を常に表示し、右側にメインコンテンツを表示する
- サイドバーのメニュー構成:

```
売上管理
  ├ ダッシュボード
  └ 売上詳細(年月別)
案件管理
  └ 案件一覧
人事管理
  └ 社員一覧
─────────
ログアウト
```

- 今いるページのメニューは強調表示する
- スマートフォンなど狭い画面では、サイドバーをハンバーガーメニューで開閉する

### 3.2 画面一覧
| No | 画面名 | URL(案) | 概要 |
| --- | --- | --- | --- |
| S-01 | ログイン | `/login` | メールアドレス・パスワードでログイン |
| S-02 | 売上ダッシュボード | `/sales` | 売上のグラフと指標を表示 |
| S-03 | 売上詳細(年月別) | `/sales/details` | 指定した年月の売上明細の表 |
| S-04 | 案件一覧 | `/projects` | 案件の表。行をクリックすると詳細ポップアップを開く |
| S-05 | 案件詳細ポップアップ | (S-04上のモーダル) | 担当者・詳細・納期などを表示・編集 |
| S-06 | 社員一覧 | `/employees` | 社員の表 |
| S-07 | 社員詳細 | `/employees/[id]` | 個人情報・給料履歴・参加案件 |
| S-08 | CSV/Excel取り込み | (各一覧画面のダイアログ) | 売上・案件・社員を一括登録 |

## 4. 機能要件

### 4.1 売上管理

#### 4.1.1 売上ダッシュボード(S-02)
| No | 機能 | 内容 |
| --- | --- | --- |
| F-S01 | 月別売上推移グラフ | 直近12か月の月別売上を棒グラフで表示。前年同月の値を折れ線で重ねる |
| F-S02 | 前年同月比 | 当月の売上と前年同月比(%)をカードで表示 |
| F-S03 | 目標達成率 | 月ごとの目標売上を設定でき、当月・年度累計の達成率を表示 |
| F-S04 | 案件別売上内訳 | 期間内の案件別売上を上位順に表示(グラフ+表) |
| F-S05 | 顧客別売上内訳 | 期間内の顧客別売上を上位順に表示(グラフ+表) |
| F-S06 | 期間切替 | 表示する年度・期間を切り替えられる |

#### 4.1.2 売上詳細(年月別)(S-03)
| No | 機能 | 内容 |
| --- | --- | --- |
| F-S11 | 年月選択 | 年・月を選択して、その月の売上明細を表示 |
| F-S12 | 明細表 | 列: 計上日 / 案件名 / 顧客名 / 金額 / 備考。合計金額を表示 |
| F-S13 | 並び替え・検索 | 列ごとの並び替え、案件名・顧客名での絞り込み |
| F-S14 | 登録・編集・削除 | 画面から売上明細を登録・編集・削除できる |
| F-S15 | CSV/Excel取り込み | 売上明細を一括登録できる(4.4参照) |
| F-S16 | 目標売上の登録 | 月ごとの目標売上を登録・編集できる |

### 4.2 案件管理

#### 4.2.1 案件一覧(S-04)
| No | 機能 | 内容 |
| --- | --- | --- |
| F-P01 | 案件一覧表 | 列: 案件名 / 顧客名 / 担当者 / ステータス / 開始日 / 納期 / 進捗率 / 契約金額 |
| F-P02 | 絞り込み・検索 | ステータス・担当者・顧客で絞り込み、案件名で検索 |
| F-P03 | 並び替え | 納期・契約金額などの列で並び替え |
| F-P04 | 納期の警告 | 納期が近い案件(7日以内)と納期を過ぎた案件を色で強調する |
| F-P05 | 新規登録 | 「新規案件」ボタンから登録フォームを開く |
| F-P06 | CSV/Excel取り込み | 案件を一括登録できる(4.4参照) |

#### 4.2.2 案件詳細ポップアップ(S-05)
表の行をクリックすると、モーダルで次の内容を表示する。

| 項目 | 内容 |
| --- | --- |
| 案件名 | |
| 顧客名 | |
| 契約金額 | 円 |
| ステータス | 見積中 / 進行中 / 納品済 / 請求済 / 失注(案) |
| 担当者 | 複数人を設定でき、うち1名を主担当にする。社員マスタから選ぶ |
| 開始日 | |

- ポップアップの中で編集・保存・削除ができる

### 4.3 人事管理

#### 4.3.1 社員一覧(S-06)
| No | 機能 | 内容 |
| --- | --- | --- |
| F-H01 | 社員一覧表 | 列: 社員番号 / 氏名 / 部署 / 役職 / 入社日 / 現在の給料 / 参加案件数 |
| F-H02 | 絞り込み・検索 | 部署・役職・スキルで絞り込み、氏名で検索 |
| F-H03 | 新規登録 | 社員を登録できる |
| F-H04 | CSV/Excel取り込み | 社員を一括登録できる(4.4参照) |

#### 4.3.2 社員詳細(S-07)
| 区分 | 項目 |
| --- | --- |
| 基本情報 | 社員番号 / 氏名 / 氏名(カナ) / 部署 / 役職 / 入社日 / メールアドレス / 電話番号 / 在籍状況(在籍・休職・退職) |
| 給料 | 現在の給料(月額)/ 給料履歴(適用開始日・金額・変更理由) |
| スキル・資格 | スキル(複数)/ 資格名・取得日(複数) |

- 各項目を編集・保存できる
- 給料を変更したときは履歴に1行追加する(上書きしない)

### 4.4 CSV/Excel取り込み(共通)
| No | 内容 |
| --- | --- |
| F-I01 | 対応形式: `.csv`(UTF-8 / Shift_JIS)、`.xlsx` |
| F-I02 | 画面ごとにテンプレートファイルをダウンロードできる |
| F-I03 | 取り込む前にプレビューを表示し、エラーのある行(必須項目が空、日付や数値の形式が違う、参照先が存在しない等)を示す |
| F-I04 | エラーのない行だけを登録するか、全件取り消すかを選べる |
| F-I05 | 顧客名・社員番号などで既存データとの対応付けを行う |

### 4.5 共通機能
| No | 内容 |
| --- | --- |
| F-C01 | ログインしないとすべての画面を利用できない |
| F-C02 | 金額は円で、3桁ごとにカンマを付けて表示する |
| F-C03 | 削除の前に確認ダイアログを表示する |
| F-C04 | 登録・更新した日時と更新者を記録する |

## 5. データ項目(概要)

```
customers(顧客)      : id, name, created_at, updated_at
projects(案件)       : id, name, customer_id, contract_amount, status,
                         start_date, due_date, progress, description, ...
project_members        : project_id, employee_id, role, is_primary
sales(売上明細)      : id, project_id, customer_id, recorded_on, amount, note, ...
sales_targets(目標)  : year_month, target_amount
employees(社員)      : id, employee_no, name, name_kana, department, position,
                         hire_date, email, phone, status, ...
salary_histories       : id, employee_id, effective_from, amount, reason
employee_skills        : employee_id, skill
employee_qualifications: id, employee_id, name, acquired_on
```

- 案件・社員・顧客はすべてのデータで共通に使い、二重に登録しない
- 「参加している案件」は `project_members` から取得する

## 6. 非機能要件

| 区分 | 要件 |
| --- | --- |
| 対応ブラウザ | Chrome / Edge / Safari の最新版 |
| 対応端末 | PCを主な利用端末とし、スマートフォンでも閲覧できるようにする |
| 性能 | 一覧画面は1,000件程度のデータで2秒以内に表示する |
| セキュリティ | 通信はHTTPSのみ。ログインユーザー以外はDBにアクセスできないようにする(Supabase RLS) |
| 個人情報 | 給料などの個人情報を扱うため、社外への公開・共有はしない |
| バックアップ | Supabaseの自動バックアップを利用する |
